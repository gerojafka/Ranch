# Petite Prairie — publication GitHub Pages

Ce dossier est prêt à publier tel quel. Le fichier `index.html` contient tout le jeu.

1. Créez un dépôt GitHub public, par exemple `petite-prairie`.
2. Déposez `index.html` et `.nojekyll` à la racine du dépôt.
3. Dans **Settings → Pages**, choisissez **Deploy from a branch**.
4. Sélectionnez la branche `main` et le dossier `/ (root)`, puis enregistrez.
5. L’adresse sera `https://VOTRE-NOM.github.io/petite-prairie/`.

La progression est enregistrée dans le stockage local de chaque navigateur pour cette adresse. Utilisez Paramètres → Sauvegarder pour télécharger un fichier JSON et Paramètres → Charger pour le réimporter.
